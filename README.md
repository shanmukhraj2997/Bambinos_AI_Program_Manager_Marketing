Bambinos.live — AI Program Manager (Marketing) Take-HomeRepository: Bambinos_AI_Program_Manager_MarketingAssignment: AI-enabled pipeline for finding parent-relevant short-form moments in live-class recordingsCurrent status: Public GitHub repository and end-to-end tested n8n automation MVP uploaded; final review and Google Form submission remain pending.1. Project objectiveThis project presents a repeatable, no-code / AI-assisted process for identifying authentic 10–20 second learning moments from long live-class recordings, evaluating their parent-facing value, screening for unsuitable content, verifying selected moments against the original recordings, and preparing editor-ready Ad Creative Briefs for human review.The aim is to reduce manual review effort while preserving educational authenticity, child privacy, safeguarding and human approval.2. Workflow overviewObtain the session reference, original recording and timestamped WebVTT transcript.Analyse the transcript using the versioned system prompt.Identify potential 10–20 second moments and log timestamps, dialogue, taxonomy, scores and compliance flags in the tracker (either directly or via the tested n8n Candidate Intake Form workflow).Reject or escalate content that triggers a hard exclusion.Have a human reviewer inspect each candidate in the original recording, including surrounding context, audio and visual evidence.Confirm guardian marketing consent, privacy requirements and any necessary cultural or contextual review.Prepare an Ad Creative Brief and hand off only candidates that have received all required approvals.Have the editor produce a draft, followed by marketing and safeguarding quality checks before any advertising use.The AI output is a candidate recommendation, not an approval decision. A transcript alone cannot establish visual quality, actual audio clarity, a child's comfort, consent or the full classroom context. Human review is mandatory.5. Scoring and decision rulesThe ten-point rubric uses:Parent learning value: 0–2Scroll-stopping hook: 0–2Child participation: 0–2Positive authentic emotion: 0–1Visual potential: 0–1Audio clarity: 0–1Sound-off readability: 0–1Hard exclusions override scores. These include child or family identifying information, embarrassment or distress, teacher shaming or threatening behaviour, inappropriate interactions, unverified outcome claims, misleading edits, private information on shared screens, missing consent and material that cannot responsibly be cleared.The tracker total uses:=IF(COUNT(J2:P2)=7,SUM(J2:P2),"")
The formula calculates a total only when all seven score cells contain numeric values. Missing scores remain blank rather than being treated as zero.6. Tools and implementation statusTo maintain strict transparency between what has been built, tested and planned, this project is structured across three clearly separated layers:A. Completed Prompt-and-Tracker Prototype (Core Assignment Deliverables)AI content analysis: ChatGPT using the versioned system prompt (prompts/01_content_mining_system_prompt.md) across all four official subjects (English, Gita / Little Yogi, Maths and Science).Tracking and scoring: Google Sheets / Excel-compatible 22-column candidate tracker (results/Bambinos_AI_Content_Mining_Tracker.xlsx) with automated score-validation formula.Audio-visual verification: Manual review of the original class recordings for ENG-001, GIT-001 and SCI-001, plus five documented hard-exclusion rejections (results/rejected_moments.md).Documentation and handoff: Three editor-ready Ad Creative Briefs (results/ad_briefs/), SOP, workflow architecture and the compulsory case report PDF (Bambinos_AI_Program_Manager_Case_Report.pdf).B. Tested n8n Automation MVP (workflows_or_scripts/n8n/)Implemented and end-to-end tested workflow: A local self-hosted n8n (v2.46.6) workflow running in Docker Desktop on Windows 11 (Bambinos_Candidate_Intake_Review_Gate_v2.json) connected to Google Sheets via OAuth2 API.Three-node architecture:Candidate Intake Form (formTrigger v2.2): Collects anonymised candidate metadata, timestamps, seven-component rubric scores, compliance flags and human review statuses with a mandatory operator attestation checkbox.Validate Scores and Apply Review Gates (code v2): Validates required fields, parses HH:MM:SS.mmm timestamps, enforces the 10–20 second duration window, verifies integer score ranges (0–10 total), enforces hard-exclusion overrides and assigns a cautious gate classification.Append Review Record to Google Sheets (googleSheets v4.7): Appends validated 28-column records to a dedicated Automation Intake tab in the Google Sheets tracker without overwriting the main Candidate Tracker tab.Verified safeguarding and gate outcomes: Tested end-to-end with synthetic, non-identifying records (workflows_or_scripts/n8n/TEST_RESULTS.md). Hard exclusions, failed privacy reviews or failed visual verification automatically classify the record as Rejected, withhold all numerical scores (leaving score cells blank) and redact the dialogue field to [REDACTED — rejected record; do not reproduce]. Pending consent or scores below 7/10 hold the record in Needs Review. When all intake checks pass, the maximum automated classification is Eligible for Editor Review—never automatic advertising approval.C. Privacy and responsible sharingThe original classroom recordings and complete raw WebVTT transcripts are intentionally not included in this public repository. They should remain in appropriately access-controlled storage. Do not commit raw recordings, complete transcripts, children's names, ages, contact details, school or family information, or screenshots that reveal identifying data.All end-to-end tests of the n8n workflow (workflows_or_scripts/n8n/) were conducted exclusively using synthetic, non-identifying test records. Exported workflow JSON files have OAuth credentials and live spreadsheet IDs sanitised (REPLACE_WITH_YOUR_GOOGLE_SPREADSHEET_ID).A Verified - Pass value in the tracker or an Eligible for Editor Review status in the n8n intake gate does not mean that a candidate is approved for advertising. All three real candidates (ENG-001, GIT-001 and SCI-001) currently remain Needs Review and are not cleared for advertising.8.
